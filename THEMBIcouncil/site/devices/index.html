REAL ENDPOINT AGENT

Install the device connector

Pair a Windows, Mac or Linux computer to THEMBIcouncil with per-action local permission.

PluginCloud MCPDevice connector

1. Download the agent

The original Council Cloudflare Worker already implements device registration and job delivery. This standalone Python 3.10+ connector implements its actual /agent/claim, /agent/poll, and /agent/result protocol. It needs no third-party Python packages.

Download the device connector source

Windows setup script (.ps1)Mac/Linux setup script (.sh)

The optional setup scripts only download the pinned Python connector into your own user directory and check Python compilation. They do not pair, install privileged services or start background access. Review before executing.

Save it as thembicouncil_agent.py and review permissions before running. It runs visibly in a terminal; it is not an invisible background monitor.

2. Prepare Python

Windows: Install Python 3.10+ from python.org, then open PowerShell in the folder where you saved the script.

Mac: Use an installed python3 3.10+ and Terminal. For Linux use an equivalent shell and Python 3.10+.

python --version

On Windows, py -3 can be substituted for python.

3. Create the one-time device code

In the separately authenticated Council MCP, invoke council.devices.enroll. It issues a single-use code valid for 10 minutes. Keep it private. A public website cannot generate such a code without the person's authenticated MCP grant.

4. Pair your Windows computer

In PowerShell, after saving the script, use a specific personal folder (not an entire drive):

py -3 thembicouncil_agent.py pair --label "Thembi Windows" --root "$HOME\Documents"

Enter the code when prompted. The program stores the device token using the Windows account's DPAPI facility.

On macOS or Linux

python3 thembicouncil_agent.py pair --label "Thembi Mac" --root "$HOME/Documents"

On macOS/Linux the token is in an owner-only directory with restrictive filesystem permissions. Pairing requires the device owner's confirmation.

5. Run the connector

python3 thembicouncil_agent.py run

On Windows, use py -3 thembicouncil_agent.py run. Leave this terminal running while you want the Council to reach your device. Every requested file or command action displays its exact arguments and must be approved by typing YES.

Request a council.devices.list status refresh, submit a bounded read inside the allowed folder, and inspect its council.jobs.result receipt. Pairing and file execution are not complete until a real device demonstrates a completed job.

Security & permissions

  • The cloud cannot read folders you have not explicitly allowed.
  • Local terminal commands use an executable allowlist, never an unapproved shell string; the operator must consent to each command.
  • Files are bounded to 60 KB for this protocol; only UTF-8 file transfer is supported.
  • Use council.devices.revoke to disable a paired endpoint immediately.
  • Press Ctrl+C to stop polling. Closing the terminal stops access.

The new connector has been committed against the live Worker contract but has not passed an end-to-end Windows/Mac device pairing test. The cloud Worker alone is not proof that this script has been installed or accepted on Thembi's computer.

Android and iPhone

Android: The Council Worker does not currently accept an Android platform in its claim endpoint. Phone-MCP is a separately installable Android companion with its own server and consent. It is not silently federated with this agent.

iPhone/iPad: iOS cannot run this desktop Python agent in the background with general-purpose file and shell permissions. Use selected Files/Share actions or an authorized Mac endpoint.
