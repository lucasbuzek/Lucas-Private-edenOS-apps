Existing deployed MCP server

Service: THEMBIcouncil MCP v0.2.0 · Cloudflare Worker · Streamable HTTP · D1 private storage.

Public service (information only): thembicouncil-mcp.lucasravensnest.workers.dev

Private connection format:

https://thembicouncil-mcp.lucasravensnest.workers.dev/mcp/<individual-secret>

This is a format, not an issued connection. Never substitute a Cloudflare administrative identity, share a connection token publicly, or reuse another person's link.

How to connect

  1. Sign into the ChatGPT account that will own the Council.
  2. From Settings / Plugins, use Add custom MCP if the account exposes that option.
  3. Obtain an individually provisioned URL from the Council owner. Enter it as the MCP server URL using a compatible client.
  4. After successful connection, invoke council.status and confirm the displayed principal.
  5. Check council.devices.list; expect an empty list until a device is actually paired.

Client compatibility: The current Council Worker uses revocable capability URLs. Some MCP hosts require OAuth discovery and will not accept this authentication format. This specific Council endpoint has not been accepted in Thembi's ChatGPT account; do not mistake a healthy Worker for an installed connector.
