CHORUS & Terry

Select Heartbi, Fitbi, Dreambi, Bossbi, Roambi, Storybi or SexyBi inside Thembi's own personal Council. Terry is a separate companion and Chief Inspector, not an eighth CHORUS character. Switching voices does not grant access to new accounts.

Examples: Heartbi, help me organize this week · Bossbi, organize these job application deadlines · Storybi, suggest a book without spoilers · Ask Terry to inspect the garden gate.

Cloud documents already supported by the Council MCP

  1. council.status confirms the connected principal and whether devices are paired.
  2. council.cloud.list shows text documents in the individual Council D1 storage space—not in iCloud Drive or Google Drive.
  3. council.cloud.read reads one relative text path.
  4. council.cloud.write creates or versions a document; use expected_version to avoid overwriting changes.
  5. council.audit reports operations scoped to the current principal.

These are real tools in the existing Worker source; this public website does not invoke them or authenticate to a private account.

Paired device operations

  1. Choose a verified device ID from council.devices.list.
  2. Use council.device.files.list, council.device.files.read or council.device.terminal.exec only for approved directory and command scopes.
  3. The cloud queues a job and returns a receipt. It does not directly execute a shell command.
  4. The local agent must explicitly approve and execute the action; then use council.jobs.result to retrieve its completion state.

Real execution requires an independently paired, working local agent

Try it now: read a file locally

Use the native Files picker to choose a small text document, including a document from iCloud Drive on supported Apple devices. The selected text is read and previewed inside your browser. No upload, server request or Council connection occurs.
