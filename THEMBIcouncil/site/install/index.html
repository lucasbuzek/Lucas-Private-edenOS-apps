Install & connect

Install the actual Council plugin, cloud MCP and local device endpoint separately.

InstallationUsageTroubleshootingMCP connector

1. Install THEMBIcouncil in ChatGPT

The original THEMBIcouncil 0.1.26 plugin is installed as a USER/PRIVATE plugin under the creator's ChatGPT account. Its personalities, artwork and Council rules are preserved. It has not been shared or installed in Thembi's own account.

  1. On the recipient's ChatGPT account, open ChatGPT and visit Settings → Plugins.
  2. Install the exact THEMBIcouncil plugin only after the creator has granted that account a supported invitation or shared installation.
  3. Open the Council and ask CHORUS or tellMEaboutME to identify the installed version.

Important installation blocker: the current USER/PRIVATE plugin does not supply a recipient-accessible install link. A public web page, GitHub source or Cloudflare Worker is not an installed ChatGPT plugin. Do not assume installation succeeded.

2. Connect THEMBIcouncil MCP

The Cloudflare-hosted Council MCP is deployed separately. It contains cloud-file tools, account-scoped grants, device enrollment, audit and revocation. It is not the Cloudflare administrator login.

Open actual MCP server setup and supported tool list

Each person's MCP access must have its own secret URL. An existing plugin installation does not automatically connect the MCP.

3. Install and pair a device

A new standalone device agent for Windows, macOS and Linux has been added to the existing project. It implements the Council Worker's actual claim/poll/result protocol with per-action permission and approved folders.

Get the device connector, pairing commands and download

Device pairing requires an authenticated Council connection and a single-use code. No device has been paired on Thembi's behalf.

4. iPhone/iPad and Android

On Apple mobile devices, use the native Files picker, Share Sheet and authorized device-native apps. Arbitrary Windows/macOS-style terminal access does not exist in an iPhone browser.

The Council agent-claim endpoint does not yet accept Android. Phone-MCP for Android is an independent companion and needs its own private server and permission setup; it is not yet federated with this Council.

5. Verify the installed components

In the authenticated Council MCP, run council.status, council.devices.list, and check council.jobs.result after a real device action. Cloud health alone does not establish an installed plugin, accepted login or working local executor.
