Installation & connection

Install & connect

Use the existing Council and AppleRAVEN-derived deployment pattern without copying anyone else's account credentials.

InstallationUsageTroubleshootingApple services

1. Start with your own account

  1. Open ChatGPT on the account Thembi controls.
  2. Connect the existing THEMBIcouncil plugin only through a supported, authorized plugin-sharing workflow. It is currently registered privately under the developer's account; its appearance in another account has not been accepted.
  3. If custom MCP connections are available in that account, add the individual owner-issued private URL from the existing THEMBIcouncil MCP, not the base service URL.
  4. Use the public service landing for service information only. Never post or forward a private /mcp/<secret> URL.

Current Council Worker uses revocable, per-person capability links, not AppleRAVEN's full OAuth integration. Host/client support and Thembi-account acceptance are still gates.

2. Choose your platform

iPhone & iPad

In Safari, open the product website and select Share → Add to Home Screen for a website shortcut. This does not install a native device executor or give access to iCloud data.

Product shortcut available; native Council app not released

macOS

AppleRAVEN provides an existing pattern for a paired, owner-authorized Mac endpoint. Its current Lucas-only grant is not Thembi's grant. A separate Council pairing and local operator approval are mandatory.

Council device pairing contract exists; Thembi endpoint not accepted

Windows

The Council MCP already recognizes Windows enrollment and queued file/terminal tools, but no compatible signed Council Windows agent has been verified here. Private Desktop MCP is an independent existing Windows option, not automatically paired with Council.

Needs verified agent and device pairing

Android

Phone-MCP has its own Android application and self-hostable relay. It is a separate authenticated connector until its adapter is verified; the existing Council MCP agent route currently does not accept Android enrollment.

Android Council adapter not connected

3. Pair an approved device

  1. Use the authenticated Council connection to call council.status and council.devices.list.
  2. For Windows, macOS or Linux, a qualified operator calls council.devices.enroll, creating a single-use ten-minute code.
  3. Pair using a verified, trusted local endpoint agent. The Council cloud accepts enrollment claims, but that does not by itself install an agent.
  4. Keep the token in operating-system protected storage, limit directories and disable unused permissions. Verify council.devices.list reports the intended endpoint.
  5. For commands or file access, inspect the queued request and approve it locally. Revoke access with council.devices.revoke if needed.

Never substitute Lucas's AppleRAVEN device authorization or account for Thembi's independent ownership. Native agent acceptance is pending.

4. iCloud setup

  1. Sign in to iCloud.com directly, using Apple's own sign-in page.
  2. Use Apple services to open Drive, Photos, Notes, Calendar and other supported destinations.
  3. For a selected document, use the local file picker in Safari. On iOS, the Files picker may surface iCloud Drive if enabled in Settings.
  4. App-owned CloudKit sync requires an Apple Developer CloudKit container and separate user authorization; it has not been configured for this Council.
