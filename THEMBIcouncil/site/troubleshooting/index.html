Help & troubleshooting

Follow AppleRAVEN-style evidence checks: identify the connection, principal, device, permissions and actual result before changing anything.

Connection issues

Custom MCP connector cannot be added or says unsupported

Check whether the current ChatGPT account supports custom MCP. The existing THEMBIcouncil Worker uses an owner-issued capability link and does not yet offer the same OAuth handshake as AppleRAVEN. A URL that works in one MCP client may be rejected by another. Do not paste connection tokens into public chats or shared support tickets.

401 invalid or expired connection

The private Council link may be expired or revoked, or the URL may be incomplete. Obtain a new grant through the authenticated owner/provisioner. The public service root is not a valid authenticated MCP URL.

Council is responding as the wrong account

Stop. Verify the ChatGPT account and Council principal with council.status. Never reuse Lucas's private AppleRAVEN account, tokens or device grants. Thembi personal, family and Slindokuhle Transport are distinct identities.

Device issues

No paired devices appear

Pairing a device requires an approved local agent, a fresh single-use Council enrollment code, matching principal and completed claim. Creating a code alone doesn't install software. Review council.devices.list for a read-back.

Device is offline or command remains queued

The agent may not be running, allowed to connect, or ready for user approval. The Cloudflare Worker cannot execute on the device by itself. Inspect the local endpoint, network connection and consent prompt; then read the job receipt. Do not claim the queued job completed.

Windows or Android controls not available

Windows requires a verified compatible agent, not just the Council's cloud contract. Android requires a separately authorized Android adapter: the existing Council agent claim accepts Windows/macOS/Linux only. Phone-MCP can run independently after its own setup.

Apple services and visuals

iCloud files don't appear automatically

Opening an iCloud site or using Sign in with Apple doesn't give Council access to all Apple services. For selected files use the iOS/iPadOS Files picker; CloudKit can only access an app's own configured containers and requires developer setup and the user's authentication.

Photos, Notes, Contacts or Calendar are not syncing

No universal iCloud account-scanning connector has been deployed. Use authorized native picker/Shortcuts workflows for individual selected data. EventKit or other Apple frameworks need a real signed Apple app and permission grants.

Thembi's portrait looks inaccurate

Do not substitute arbitrary generated faces. The site presents existing source illustrations, not a final likeness-approved avatar. The private original references must be reconciled with Thembi before public portrait acceptance.

Illustrations fail to load

The source illustrations are hosted through their existing Dropbox links. A blocked network, removed share link or third-party media restriction can prevent display. The rest of the website remains independent. A future self-hosted asset release must preserve the original source and consent history.

Safe recovery

Never post authentication tokens, private MCP URLs, pairing secrets, iCloud credentials, screenshots of personal data or private file contents. Report only the status, tool name, timestamp, device platform and redacted error.
