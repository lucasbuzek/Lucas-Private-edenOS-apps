# ForgeMASTER v1.0 — Calls and Routing

`@forgemaster goal (...)` = normal goal execution.
`@forgemaster extendedgoal (...)` = expand intent into comprehensive execution contract, present for submission, STOP; submitted expanded contract authorizes execution.

`@forgemaster handofffull` → shared HANDOFF CORE → portable destination-neutral continuation package.
`@forgemaster backupfull` → shared BACKUP CORE → verified RECOVERY-level canonical backup.
`@forgemaster backuplocal` → shared BACKUP CORE → synchronized Mac offline/recovery mirror.
`@forgemaster handoffCodex` → HANDOFF CORE + CODEX ADAPTER → executable task → offer Start Codex: CLOUD | LOCAL | MIXED → explicit confirmation before new session/task.
`@forgemaster handoffClaude` → HANDOFF CORE + CLAUDE ADAPTER → self-contained Claude-compatible development-team package.

HANDOFF CORE inherits authority/Project Bible/global canon recovery, repository/branch/worktree/LKG/candidate, product definition, evidence states, completed/in-progress/unfinished/failures/regressions/blockers, manifest/provenance, continue-work rule, deterministic next gate/action, recovery location.

BACKUP CORE inherits source/history/canon/config/assets/tests/docs/evidence/LKG/candidate/environment/dependencies/failures/blockers/handoff/continuation, safe secret handling and transactional verification.

Universal continuation: MILESTONE REACHED WITH EVIDENCE or GENUINELY BLOCKED. Repairable failure follows FAIL → CAPTURE EVIDENCE → DIAGNOSE → CHANGE SOMETHING MEANINGFUL → RETRY → REVERIFY → CONTINUE.

Legacy EITRI/EITRIMB handoff definitions are provenance, not parallel governance. Compatible legacy names may exist only as aliases routed through ForgeMASTER shared cores.
