# silentChatGPT — UNIVERSAL APPDEV CANON

Status: AUTHORITATIVE UNIVERSAL APPDEV RULE

Canonical definition: silentChatGPT is the Private/Custom Apple local-first escalation mechanism. The originating standalone app owns its deterministic domain logic, local/native Apple intelligence, escalation decision, privacy/context reduction, validation, provenance and UI. When local/native intelligence cannot reliably resolve a difficult bounded task, the app may escalate the minimum necessary text/structured context through an Apple-supported system path such as Shortcuts Use Model -> configured Extension Model -> ChatGPT. The result returns to the originating app, which validates it and remains authoritative.

Rules:
- local/native capability first; escalate only when needed;
- no HEIMDALL, BIFROST, CONDUCTOR or other EDEN dependency is implied;
- no separate ChatGPT UI, website automation or copy/paste workflow;
- Apple's configured ChatGPT extension is not an unrestricted OpenAI API and a consumer ChatGPT subscription is not arbitrary API access;
- images/screenshots/photos/PDFs/documents are processed locally first with native acquisition, Vision/OCR/VisionKit/document parsing/native models; normally only the minimum relevant derived text/structure is escalated;
- raw attachments are not silently transmitted; exceptional raw transfer follows explicit platform/user authorization and Apple confirmation behavior;
- send the smallest sufficient problem: objective, relevant extracted evidence/normalized data, evidence IDs, local attempt, unresolved conflict and required output schema;
- never send unrelated databases, holdings, files, credentials, secrets or whole conversation history without explicit necessity/authorization;
- model output is reasoning/interpretation input, not authoritative domain state; deterministic/domain validation applies before mutation;
- provider/privacy controls and meaningful failures remain visible; “silent” means no unnecessary provider ceremony, not concealed transmission or bypassed permissions;
- if unavailable, continue possible local/deterministic work, use another authorized provider only when project canon permits, and expose unresolved state rather than fabricate completion;
- apps may expose App Intents/App Shortcuts so Siri can invoke them directly; Siri may also use its own escalation. Neither path creates dependency on the other;
- Private/Custom Apple profiles may enable silentChatGPT as preferred escalation; Official portable apps do not become ChatGPT-dependent unless their Project Bible explicitly says so.

Verification must cover as applicable: real App Intent/Shortcut invocation, local-first behavior, bounded structured escalation, configured Extension Model/ChatGPT path, return to originating app/surface, raw assets remaining local in normal operation, validation before authoritative mutation, and graceful provider failure. Compilation alone is not verification.

UNIVERSAL INVARIANT:
silentChatGPT = LOCAL/NATIVE FIRST + APP-OWNED ESCALATION DECISION + APPLE-SUPPORTED CHATGPT EXTENSION HANDOFF + MINIMUM NECESSARY CONTEXT + RESULT RETURNS TO ORIGINATING APP + DETERMINISTIC VALIDATION.
