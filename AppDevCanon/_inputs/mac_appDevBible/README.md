# #appDev Bible

Global authoritative EDEN/AppDev engineering canon for all current and future software-development projects.

Canonical authority files:
- `APPDEV_BIBLE.txt` — universal development rules.
- `namingRules.txt` — naming authority.
- `DESIGN_MANTRA.txt` — recovered product/engineering doctrine.
- `GMR.txt` — GrandMasterRegister catalogue rules.
- `Project Bibles/<PROJECT>.txt` — project-specific recovered canon.

EITRIMB is a thin Master Builder governor and inherits these rules. It must not duplicate universal canon into its own prompt. Project-specific rules must be recovered from project/conversation authority rather than inferred from this global Bible.

Canonical persistent projects: `~/edenOS/Projects/<Project>/`.
Disposable project work: `~/edenOS/Temporary/<Project>/`.
