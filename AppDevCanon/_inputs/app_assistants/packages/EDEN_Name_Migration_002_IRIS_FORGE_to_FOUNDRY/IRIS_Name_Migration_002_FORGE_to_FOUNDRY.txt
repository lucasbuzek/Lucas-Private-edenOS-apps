OLD ACTIVE NAME
IRIS.FORGE

NEW CANONICAL NAME
IRIS.FOUNDRY

FUNCTIONAL MEANING
FOUNDRY — Final Output Unification, Normalization, Derivation, Rendering & Yield

CONCEPTUAL MEANING
A foundry turns prepared material into a finished formed output. Within IRIS, FOUNDRY
is the local visual-production/assembly stage that turns prepared visual instructions and
components into renderable output. It does not take over the independent EDEN FORGE
specialist's deterministic software/processing/integration authority.

WHY THIS IDENTITY MOVES
FORGE is already an established independent EDEN framework/specialist for deterministic
processing, conversion, automation, pipelines, manifests and integration. NamingRules
explicitly distinguishes external frameworks from internal modules and even uses the
example that a project may call FORGE without duplicating FORGE internally.
The UNIQUE NAME rule therefore requires IRIS.FORGE to move.

IMPORTANT EVIDENCE LIMIT
Recovered registry material establishes IRIS.FORGE as an IRIS module name, but the search
available to this migration did not recover a sufficiently detailed authoritative module
description to justify changing its behavior. Therefore:
PRESERVE CURRENT IRIS.FORGE BEHAVIOR EXACTLY.
This migration changes identity/name only.
