# 1. IDENTITY

CRESUS — Capital Research & Equity Strategy

CRESUS is a worldwide investment research, information, organization, portfolio, income and strategy-analysis application family.

Inspiration: Croesus, King of Lydia, whose name became synonymous with immense wealth.

Design mantra:
CRESUS THE KING.

The product experience must feel sovereign, refined, authoritative, intelligent, premium and enduring. It must not look like a casino/trading gimmick, crypto-neon dashboard, generic fintech template, developer console or faux-medieval costume UI.

UI/UIX is a primary product requirement and is developed together with functionality.

# 2. PRODUCT PURPOSE

CRESUS researches, organizes, calculates, compares and explains. The user decides.

The product is not a broker, automated investment manager or trading bot.

Primary lifecycle:
Research -> Evidence -> Thesis -> Portfolio -> ZACCHAEUS -> Strategy Lab -> Intelligence.

# 6. SILENT CHATGPT — PRIVATE APPLE CANON

Private CRESUS may use ChatGPT silently as an optional behind-the-scenes intelligence provider.

Silent ChatGPT means:
- no separate ChatGPT-style UI is required;
- CRESUS invokes the provider only when its capabilities are useful;
- on-device/native processing happens first where adequate;
- minimize external context to the smallest text/structured representation needed;
- do not silently transmit raw screenshots, photos, files or unrelated private data;
- user portfolio/account/provider data is not treated as a generic AI prompt;
- provider output is analysis input, never authoritative financial state;
- deterministic CRESUS state and calculations remain authoritative;
- secrets/tokens remain in appropriate secure storage;
- the provider is replaceable and must not become a runtime dependency for core local functions.

# 9. COMMERCIAL RELEASE MODEL

The abandoned early percentage-contribution / 10% model is obsolete and must not be reintroduced.

Current model:

FREE
- deliberately bounded discovery/organization product

FULL
- permanent one-time IAP
- complete supported local/on-device CRESUS product
- complete supported native/device AI capability

INTELLIGENCE
- recurring IAP/subscription
- continuously supplied CRESUS-managed online research / external evidence / cloud AI capacity

OPTIONAL USER-CONNECTED PROVIDERS
- users may connect supported provider accounts/credentials where appropriate
- provider usage remains subject to that provider's own terms/account limits

Core commercial principle:
Pay once for software. Subscribe for services that continuously cost money to provide.

Cancelling INTELLIGENCE must never remove:
- purchased FULL
- local user data
- local research
- local portfolios/watchlists
- supported native/device AI that belongs to FULL

# 10. CRESUS INTELLIGENCE ECONOMICS

CRESUS Intelligence is a managed service, not resale of one consumer chatbot subscription per customer.

Architecture:
CRESUS users -> CRESUS Intelligence budget/capacity -> provider-independent gateway -> multiple upstream provider APIs/capacity pools

CRESUS may route by:
- capability
- quality
- latency
- cost
- availability
- privacy requirement
- task class

Use native/device AI when adequate before consuming marginal cloud capacity.

Official commercial research should support negotiated API capacity, enterprise/volume arrangements, batching/caching and provider diversification where useful.

# 13. ZACCHAEUS

ZACCHAEUS — Dividend & Income Collector
Identity: The Collector
Core question: Where's my money?

Owns dividend/investment-income tracking and calendar.

Dividend/income states must remain separate:
- REALIZED
- DECLARED
- FORWARD INDICATED
- ESTIMATED

Never silently blend them.

Lifecycle may include:
Estimated -> Declared/Announced -> Confirmed -> Ex-Date Passed -> Record Established -> Payable -> Paid -> Reconciled
with exceptions such as changed, deferred, cancelled, missed/unreconciled.

# 14. EXPERT — COMPLETE OR EXHAUST

Expert is a completion contract.

One invocation continues the safe research cycle until:
A. COMPLETE
or
B. EXHAUSTED / PARTIALLY COMPARABLE after meaningful changed-source/method attempts.

Required behavior:
- define research universe
- build evidence matrix before synthesis
- identify missing/stale evidence
- internal research queue
- retry with changed source/query/route/method
- post-results event sweep
- synchronized comparison-clock integrity
- deterministic calculations
- evidence challenge
- explicit completion gate
- Research Snapshot

Do not hand known next research actions back to the user when CRESUS can safely execute them.

# 17. STRATEGY LAB

Strategy Lab uses a SimulationClock.

For each simulated time:
advance clock -> reveal only evidence known at/before clock -> evaluate strategy -> execute simulated trades -> apply costs/taxes/FX -> process corporate actions/dividends -> record state.

Must guard against:
- look-ahead bias
- survivorship bias
- delisting omission
- corporate-action errors
- revised-fundamental leakage
- dividend/adjusted-price double counting
- stale FX
- tax/cost/slippage omissions
- benchmark mismatch
