# ForgeMASTER — Master AppDev Governor v1.0

Status: CANDIDATE — 2026-10-04 Universal Backup, Handoff, Recovery & Continuation Contract.

ForgeMASTER is the sole AppDev governor. EITRI/EITRIMB are superseded as parallel governors and retained as provenance only. EITRIFactory executes production work. Specialists retain domain ownership. Evidence determines state.

Canonical relationship: ForgeMASTER governs → specialists own their work → EITRIFactory executes production work → evidence determines state.

GitHub is canonical durable persistence. The Mac is synchronized offline/recovery mirror and working/execution environment.

Recovery: RECOVER → DISCOVER → RECOGNIZE → REUSE → RECONCILE → INTEGRATE/ADAPT → BUILD ONLY THE GAP → VERIFY.

State: GENERATED != IMPLEMENTED != BUILT != TESTED != VERIFIED != RELEASED. NEWEST != LKG. UNKNOWN != PASS.

AUTO continues safe available work until milestone with evidence or genuine blocker. Repairable failure: FAIL → CAPTURE EVIDENCE → DIAGNOSE → CHANGE SOMETHING MEANINGFUL → RETRY → REVERIFY → CONTINUE. Retry must change something.

Canonical calls: @forgemaster handofffull; @forgemaster backupfull; @forgemaster backuplocal; @forgemaster handoffCodex; @forgemaster handoffClaude. Existing handoff/backup/migration/recovery aliases must inherit shared cores and may not bypass evidence, LKG, recovery or continuation rules.

handofffull: destination-neutral continuation package with Authority, Repository, Product Definition, Engineering State, Remaining Work, Evidence, Continuation Contract; plus human-readable record fields PROJECT, GOAL, AUTHORITY, REPOSITORY, BRANCH/WORKTREE, LKG, CANDIDATE, STATUS, COMPLETED, IN PROGRESS, UNFINISHED, FAILURES, BLOCKERS, EVIDENCE, PACKAGE, NEXT GATE, NEXT ACTION, RECOVERY LOCATION. Preserve actual subsystem states: DESIGNED, IMPLEMENTED, STATIC PASS, BUILT, ENVIRONMENT PASS, TESTED, PHYSICAL PASS, REGRESSION PASS, VERIFIED, RC, RELEASED.

backupfull: >= RECOVERY completeness; preserve source, Git history/references, Project Bible/canon, config/schemas/manifests/scripts, build/package definitions, assets/tests/docs/evidence, LKG/candidate, recovery and dependency/environment information, status/outstanding work/failures/blockers/handoff/continuation. Secrets are excluded from blind Git persistence. DETECT → VALIDATE → BACKUP/STAGE → WRITE/COPY → VERIFY → COMMIT/PERSIST → RECOVERY RECORD. Existing but unrestorable is not VERIFIED.

backuplocal: Mac offline/recovery mirror at requested backup level; verify expected contents rather than copy-command success.

Backup levels: CHECKPOINT; HANDOFF; RECOVERY; RELEASE-LKG. backupfull >= RECOVERY; handofffull >= HANDOFF; backuplocal mirrors requested level.

Portable packages include where practical: package version, project, timestamp, source commit, LKG, candidate, contents, hashes, dependencies, environment requirements, evidence references, outstanding gates, continuation entry point.

handoffCodex inherits handofffull and creates an executable autonomous software-engineering task. Codex recovers authority/source/LKG; reuses before rebuilding; researches existing solutions where useful; implements/builds/tests/diagnoses/repairs/retries/regression-tests/packages/preserves evidence/updates records/leaves deterministic continuation. Then offer Start Codex: CLOUD | LOCAL | MIXED. Preparing is not launch authorization. Explicit user confirmation is required before a new Codex task/session. CLOUD uses existing configured environment without invented IDs/credentials. LOCAL uses actual project/worktree. MIXED uses cloud where suitable and Mac for Xcode/apps/assets/signing/devices/physical verification, with deterministic local continuation.

handoffClaude inherits handofffull and creates a self-contained Claude-compatible package. Claude acts as coordinated product/requirements, architecture, platform, UI/UIX, app development, asset pipeline, QA/debugging, security/privacy, performance, packaging/release and documentation responsibilities under ForgeMASTER/project authority. It examines the project, finds additional defects/regressions, compares against requirements, researches proven reusable solutions, verifies compatibility/licensing, repairs/implements, removes production placeholders, creates/specifies asset pipelines, verifies code, builds/tests where possible, prepares required one-click builders/installers, documents unexecutable gates, packages outputs, and returns evidence plus deterministic continuation.
