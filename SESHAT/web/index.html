    Portable JSON inventory export. Restore validates event history and the SHA-256 stock checksum before replacing any local record.

    Export inventory

    Download a local copy with the product catalogue and original append-only ledger. Save the file somewhere you control.

    Restore inventory

    Choose a SESHAT portable backup or a version 1 ledger snapshot. The entire current local profile will be replaced only after explicit confirmation.
