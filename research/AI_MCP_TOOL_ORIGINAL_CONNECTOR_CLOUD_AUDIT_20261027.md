## Audited public upstream signals (current pages, independent of original .webarchive bodies)
1. Chrome explicitly says WebMCP is ephemeral frontend/browser-tab tools, not a replacement for server-side MCP (https://developer.chrome.com/docs/ai/webmcp/compare-mcp). Chrome 149 origin trial, local flag and limitations documented: https://developer.chrome.com/docs/ai/webmcp .
2. Cloudflare Browser Run is hosted browser automation and quick actions, a third capability distinct from browser WebMCP and remote authenticated MCP service: https://developers.cloudflare.com/browser-run/ .
3. Apple/macOS Automator MCP depends on real Mac host, Node.js 24+ and macOS Automation/Accessibility permissions; cannot obtain these from cloud listing: https://github.com/steipete/macos-automator-mcp .
4. BrewUI is an official Homebrew SwiftUI graphical package manager with AGPL-3.0 source license: inspect obligations before reuse in Toolkit; do not claim it is already installed: https://github.com/Homebrew/BrewUI .
5. Microsoft Playwright MCP is browser control via structured accessibility snapshots, Node.js 20+; optional worker and should not duplicate existing authorized browser integrations: https://github.com/microsoft/playwright/blob/main/docs/src/getting-started-mcp.md .
6. Tailscale app connectors route through an actually enrolled tailnet device, not a magic proxy that bypasses device connectivity. Account/tailnet status is NOT available in this chat: https://tailscale.com/docs/features/app-connectors .
