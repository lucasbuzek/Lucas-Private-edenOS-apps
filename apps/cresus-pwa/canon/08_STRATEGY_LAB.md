# STRATEGY LAB

Purpose: examine investment strategies historically without leaking future information into the past.

## SimulationClock
For each simulated time:
advance clock
-> reveal only evidence known at/before clock
-> evaluate strategy
-> simulate trades/actions
-> apply defined costs/taxes/FX
-> process corporate actions/dividends
-> record state.

## Required bias/error controls
- look-ahead bias;
- survivorship bias;
- delisting omission;
- corporate-action errors;
- revised-fundamental leakage;
- dividend/adjusted-price double counting;
- stale FX;
- omitted tax;
- omitted transaction costs/slippage;
- benchmark mismatch.

## Strategy result
Where evidence permits report:
- definition/rules;
- universe;
- period;
- data availability;
- assumptions;
- benchmark;
- total return;
- income;
- drawdown/risk;
- turnover/costs;
- scenario sensitivity;
- missing/exhausted evidence;
- limitations.

Never present a backtest as guaranteed future performance.
