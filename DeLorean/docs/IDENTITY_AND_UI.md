# DeLorean TimeMachine — cross-platform product identity and UI (Apple review retained)

**Name:** DeLorean TimeMachine (current user-corrected display name; preserve historic aliases only as provenance).
**Tagline:** Every project. Every version. A way back.
**Icon direction:** precision chronometer combined with timeline/return motif (not a film vehicle or copied movie artwork).
**Visual language:** graphite navy `#0E1522`, stainless `#A9BDD0`, timeline cyan `#66D7FF`, cautious/restore amber `#E7AC68`, verified green `#72DBA7`; semantic high contrast.
**Information architecture:** projects -> timeline -> checkpoint inspector -> compare -> preview -> isolated recovery.
**macOS:** sidebar, scrollable timeline and inspector. Offline index and isolated staging are native-local functions; no online provider required after provisioning.
**iPhone:** privacy-scoped **read-only** companion via catalog import; cannot overwrite projects or grant access to other Councils.
**Accessibility:** native focus order, keyboard, VoiceOver labels, color+text state coding, text scaling, light/dark adaptive palette, reduced-motion protection.
**Identity/license:** inspiration from 1980s time-travel fiction is conceptual; movie-specific character imagery/branding requires rights clearance for distribution. Do not depict unlicensed actors or claim sponsorship.
**Acceptance:** test actual original UI against this proposal before adopting. Do not replace accepted visuals by decree.


## Additional cross-platform UX scope (2026-10-29)
The established clock/time-circuit identity, colors, visual language and hierarchy are SHARED across native macOS, Windows, Linux, iOS/iPadOS, Android and web/PWA clients. Platform-native conventions apply: Windows keyboard/Windows UI and accessible system dialogues; Linux distro toolkit + portals and screen readers; iOS/iPadOS native sandbox, Files/document picker and Dynamic Type/VoiceOver; Android storage access framework, TalkBack and dynamic text; web keyboard/ARIA, responsive/adaptive offline UI. Agent-host cards retain matching identity, but not every host supports custom icons or MCP Apps. Do not label planned clients as built. The current SwiftUI companion is APPLE-ONLY SOURCE, not the universal application.
