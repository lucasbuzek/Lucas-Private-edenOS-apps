## Canonical legal object contract

Agreement: `agreement_id, version, parties, defined_terms, clauses, governing_law, signature_status`.
Clause: `clause_id, parent_agreement, source_reference, original_text, category, cross_references, interpretations, risks`.

Only populate fields supported by actual evidence; absent fields must be explicitly UNKNOWN rather than fabricated.
