Product overview

THEMIS is the EDEN legal-domain application and master legal helper. Its established role is to organize legal meaning and workflows around matters, parties, agreements, clauses, obligations, jurisdictions, evidence, correspondence, research, deadlines, versions and approvals.

THEMIS has two distinct surfaces: a canonical helper definition for conversational legal-domain work, and a small local Python implementation that stores structured legal-domain records. The helper prompt defines intended reasoning, handoffs and authorization boundaries. The recovered software baseline implements the record store and command-line operations; it is not a complete legal research platform or a graphical legal practice-management application.

Purpose and intended users

THEMIS is intended for people who need to organize legal material, track how a document supports a matter, understand contractual structure, identify rights and obligations, prepare compliance matrices, and keep a clear distinction between source evidence, interpretation, uncertainty and decisions. It can support individual, organizational and professional workflows, but it does not replace qualified legal advice or the user's own review.

How the product fits together

The canonical helper assigns legal-domain meaning to THEMIS while keeping adjacent capabilities independently owned. ARGOS supplies external research; CHRONOS owns persistent temporal structure and deadlines; BIFROST owns canonical identity and provenance across systems; CONDUCTOR provides the chat/helper interface and may coordinate; it is not a mandatory runtime dependency; CASPER supports polished writing; MIRROR supports comparison and version review; LINGUA supports translation. These are documented role boundaries, not proof that live adapters are bundled in the v0.1.0 code.

Interfaces and platforms

The recovered software is a Python command-line package with no graphical interface in this baseline. The prompt can be used in a compatible conversational host, but the persistent control surface described in the prompt depends on host support. No separate PWA, iOS, macOS app, Windows app or Android app was found in the recovered implementation package; those platform implementations are not claimed here.

Data and integrations

  • Records are stored in a local JSON file; the default CLI path is data/themis.json.
  • Snapshots are written into a sibling snapshots/ directory.
  • Record fields and provenance are supplied as JSON objects by the user.
  • Integration descriptors exist for BIFROST, HEIMDALL and shared-capability request/response envelopes. Evidence classifies these as descriptors/contracts, not live runtime adapters.
  • The baseline uses the Python standard library and can operate offline.

Privacy, security and user control

The local implementation does not require a remote service for record-store operations. Its JSON data and snapshots are ordinary local files; the recovered baseline does not implement encryption, user authentication, access-control policy, secure multi-user sharing or a secrets vault. Protect the folder using operating-system access controls and device security. Local storage alone is not a security certification.

Analysis and recommendations are not authorization. Legal filings, notices, external communications, irreversible changes and other consequential actions require explicit user approval and the appropriate external mechanism. Jurisdiction and effective date should be established rather than assumed. Uncertain material must not be presented as definitive legal advice.

Availability and version

The working baseline is private and experimental, version 0.1.0. The master helper and specialist prompts are recovered as version 1.0 historical definitions. The v0.1.0 code is an evidence-bounded implementation, not proof of full historical feature parity. No public release or supported distribution channel is established by the recovered evidence.

THEMIS organizes legal information and supports analysis. It does not itself establish that a legal position is correct, that compliance has been achieved, or that an external legal action has been filed or accepted.
