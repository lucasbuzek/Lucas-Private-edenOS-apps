What this guide covers

This guide covers the recovered Python command-line implementation. It does not describe a graphical interface because none is included in this baseline. Conversational use of the THEMIS master prompt is separate and depends on a compatible host.

1. Prerequisites

  • Python 3.10 or newer; the package release record requires Python 3.10+.
  • Access to the THEMIS project folder on your Mac.
  • A terminal for running commands.
  • A backup location with enough space for the JSON database and snapshots.

Check the Python version:

python3.12 --version

If the command reports a version earlier than 3.10, use the installed Python 3.12 interpreter (python3.12). Do not run the application with an unsupported system interpreter.

2. Open the project and check the CLI

Open Terminal and move to the current working copy:

cd "/Users/lucas/edenOS/Software Development/THEMIS"

Then check the command help:

PYTHONPATH=src python3.12 -m themis.cli --help

The CLI requires a subcommand. Available commands are add, list, snapshot and rollback-lkg. There is no graphical screen or interactive menu.

3. Understand the data location

Without a --db option, the CLI uses data/themis.json relative to the current working directory. The store creates the file and its parent directory when needed. Snapshots are placed in a snapshots/ directory next to the selected database file.

Use the same working directory or pass an explicit database path when running commands from elsewhere. Treat the database and its snapshots as user data.

4. Add a record

Use add followed by a record kind and title. Optional --fields and --provenance values must be valid JSON objects.

PYTHONPATH=src python3.12 -m themis.cli add matter "Lease review" --fields '{"status":"open","jurisdiction":"specify jurisdiction"}' --provenance '{"source":"user supplied"}'

The command prints the created record as JSON, including its generated identifier and timestamps. Save the identifier with your own case reference if you need to correlate it with external material. Replace the jurisdiction placeholder with verified context; the example does not establish applicable law.

5. List saved records

List all records:

PYTHONPATH=src python3.12 -m themis.cli list

Filter to one category:

PYTHONPATH=src python3.12 -m themis.cli list --kind agreement

The command prints saved records as JSON. It does not offer full-text search, sorting controls, editing screens or report generation.

6. Create a snapshot

Create a named snapshot:

PYTHONPATH=src python3.12 -m themis.cli snapshot --label before-review

To mark a snapshot as last-known-good (LKG):

PYTHONPATH=src python3.12 -m themis.cli snapshot --label known-good --lkg

The command reports the snapshot path and SHA-256 hash. Keep snapshot files; they are not automatically copied to another device or cloud backup.

7. Restore the last-known-good snapshot

Run rollback only when you intend to replace current database contents with the saved LKG state:

PYTHONPATH=src python3.12 -m themis.cli rollback-lkg

The implementation verifies the stored snapshot hash before restoring. Rollback changes the current database. Before using it on valuable records, make a separate copy of the database file and confirm that the intended LKG snapshot exists.

8. Data management and limitations

  • Back up the JSON database and snapshots directory together.
  • There is no CLI delete command, no CLI update command and no dedicated import/export workflow beyond the JSON files themselves.
  • Do not manually edit the database while another process is writing to it.
  • The baseline does not encrypt data or implement application-level user accounts.
  • Do not store secrets, access tokens or unnecessary sensitive personal information in fields.

10. Safe use of legal analysis

Identify relevant jurisdiction and effective date where they matter. Keep original source text distinguishable from interpretations and assumptions. Verify authoritative sources independently for legal deadlines, obligations and current law. The command-line store records information; it does not validate legal conclusions.

Do not treat a drafted notice, recommendation or compliance status as authorization to submit or send it. External legal actions require explicit approval and the appropriate external process. Seek qualified legal advice where needed.

11. Frequently asked questions

Does THEMIS automatically research current law?

No. The helper prompt describes a role that can consume research from an appropriate capability, but the local v0.1.0 store has no built-in legal database or live legal research adapter.

Can I edit or delete a record from the CLI?

The recovered CLI does not expose update or delete commands. The underlying Python store has an update method, but using it requires code-level access. Do not edit the JSON file without a backup.

Is there an iPhone, web or desktop GUI?

No such interface is included in this recovered implementation baseline. The current software surface is a Python CLI; conversational prompt use depends on a compatible host.

Is this a released product?

No. The source release record marks v0.1.0 private and experimental, with release state NOT RELEASED.

12. Version and support

This guide describes the private experimental 0.1.0 local implementation and recovered v1.0 helper prompts. No public support address or distribution channel is established in the recovered sources. Keep the database and snapshots under your control and test restoration on a copy before relying on it for important matters.

THEMIS is a legal information organization and analysis aid. It is not a substitute for qualified legal advice and does not itself file, send or authorize legal actions.
