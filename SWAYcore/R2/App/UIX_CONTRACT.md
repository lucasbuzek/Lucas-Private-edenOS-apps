# UIX Contract
Consumer navigation: HOME · MOVES · BEATS · PROFILE.
Final Alpha UI is a consumer dance/fitness product, not developer cards.

HOME: strong Lucia presence, start/resume, useful progress.
MOVES: visual library, large scalable demonstration, Learn/Practice/Create relationships.
LEARN: Lucia dominates; counts 1–8; user tempo; play/pause; concise synchronized instruction.
BEATS: consumer rhythm/music experience; provider internals progressively disclosed.
CALIBRATION: same future performance stage; no workout before READY.
WORKOUT: cleanest surface; large Lucia; translucent graphical YOU overlay; readable move/count/NEXT/Pause from distance.
PROFILE: YOUR DANCER, progress/history, integrations/settings.
iPad uses space for larger characters/hierarchy, not dashboard clutter.
