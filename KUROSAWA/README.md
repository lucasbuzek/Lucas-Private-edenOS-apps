# KUROSAWA

**Knowledge, Understanding & Realization Orchestrator for Screen / Audiovisual Work**

KUROSAWA is EDEN's audiovisual Director and production manager, designed to scale from short social video and Reels through documentary, episodic work and feature films.

## Surfaces
- In-chat assistant: persistent LCAS FULL production UI.
- Native iPhone/iPad app: standalone-capable mobile Director and production companion.
- Native macOS app: primary local-AI and heavy production workstation.

## Architecture
Architecture A is accepted: one Apple-native Swift/SwiftUI shared production core with platform-appropriate native interfaces. Local/on-device AI is preferred; cloud and paid providers are optional. KUROSAWA coordinates existing EDEN specialists without absorbing their authority.
