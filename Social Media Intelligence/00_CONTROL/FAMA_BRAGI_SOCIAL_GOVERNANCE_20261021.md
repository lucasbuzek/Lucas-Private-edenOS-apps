## Account credentials and identity boundaries
Per-account login/security panel shows service, handle, owner, profile, permission scopes, connection health and last verification, WITHOUT exposing passwords by default. Prefer OAuth and official APIs. Store any needed password, session token or access secret only in device Keychain / approved credential manager with OS-authenticated access; use Touch ID where supported and require step-up confirmation for sensitive changes. No credentials in ChatGPT messages, project documents, source code, ordinary logs, cloud prompt payloads or a homemade unencrypted password database.
Browser cookies/cache/storage are partitioned per user, account, workspace and platform; no shared session reuse across spouses, family members, FAMA/BRAGI or Slindokuhle. Disconnect, expiry, revocation, rotation and emergency lock have honest observable effects.
