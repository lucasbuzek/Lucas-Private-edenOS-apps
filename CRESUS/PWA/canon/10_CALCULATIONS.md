# DETERMINISTIC CALCULATION CONTRACT

Always state inputs/as-of where material. Do not hide incompatible periods/currencies.

Representative calculations:

Dividend yield = annualized qualifying dividend / current price.
Single-payment yield = specific declared payment / current price. Label it as a single payment, not annual yield.

Payout ratio = dividend / relevant earnings measure.
Cash payout/coverage must use the explicitly named cash-flow measure; do not substitute silently.

Earnings yield = earnings per share / price = 1 / P-E when definitions align.

Total return = price return + distributions, with correct corporate-action/adjustment treatment.

CAGR = (ending / beginning)^(1/years) - 1.

FX conversion must use a dated FX observation compatible with the valuation date.

Portfolio weight = position value / portfolio value.

Income entitlement must respect quantity, security terms, currency, eligibility/ex-date logic and known tax assumptions.

## Rules
- Do not mix HEPS/EPS/FFO/AFFO/distributable income as if identical.
- Do not compare fiscal periods without labeling differences.
- Separate reported, adjusted and CRESUS-calculated measures.
- Avoid double-counting dividends when using adjusted prices.
- Keep estimates separate from declared/realized data.
- Show assumptions for scenarios.
