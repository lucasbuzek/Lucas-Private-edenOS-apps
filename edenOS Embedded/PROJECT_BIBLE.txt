PROJECT BIBLE — edenOS Embedded
Target baseline: 0.1 / Samsung SM-T110 (goyawifi)
Updated: 2026-10-03

IDENTITY
edenOS Embedded is the lightweight Android-compatible embedded EDEN profile for constrained/reused hardware. First physical target: Samsung Galaxy Tab 3 Lite 7.0 Wi-Fi SM-T110/goyawifi, ARMv7, ~1 GB RAM, 1024x600. Preserve working Android hardware/runtime and normal APK compatibility while adding EDEN system/service capabilities.

PHYSICAL BASELINE — CONFIRMED
Device: SM-T110 / goyawifi.
Installed OS: Android 4.2.2 Jelly Bean.
API baseline: 17.
Build: JDQ39.T110XXUAOA1.
Kernel observed: 3.4.5-2824340.
Architecture target: ARMv7 / armeabi-v7a / 32-bit.
Do not reopen these as unknown. Samsung Quick Settings/SystemUI implementation details remain a later physical integration gate only.

CURRENT GOAL
Build the first custom edenOS Embedded testbed as a useful always-on household edge appliance that remains a normal usable tablet. Primary server workload is SKALD; secondary lightweight household server is NOSTOS; BIFROST Embedded manages device/service/connective state; SMB provides managed file access.

PLATFORM
Preserve Android/Samsung hardware support rather than replacing OS with conventional Linux for 0.1. Retain Package Manager/APKs, display, touch, Wi-Fi, audio/media, storage and power. No Google Play dependency. APK import/sideload required. Third-party APKs remain ordinary Android apps and are not rewritten/themed/wrapped by EDEN.
Android app baseline: minSdk 17; ARMv7; 1024x600; no Compose; no mandatory Google Play Services; avoid ARM64-only and modern-only dependencies. Prefer Android platform APIs and minimal deterministic libraries. Java is acceptable/preferred for tiny system-facing components where it reduces runtime/dependency cost.

FIRST APK SET
Independent APKs: edenOS Home; BIFROST Embedded; SKALD Android representation/control; NOSTOS Android representation/control; edenOS Files. No monolith.

DEVICE MODE
TABLET MODE restores normal tablet power behavior. SERVER MODE keeps configured headless services available with screen off while preserving normal tablet use when woken. BIFROST supervises service state/restart/reboot behavior. Server Mode is not Kiosk Mode. Desired control is Samsung/Android Quick Settings where safely feasible; exact SystemUI adapter remains physical-gate work.

EXPERIENCE MODE
System-wide EDEN-owned UI profile: Standard default, Simple, Child, Accessible, Kiosk. Presets may control complexity, text/control scale, density, navigation, labels, motion, contrast and advanced-control prominence. Third-party APK UI remains unchanged.

BIFROST EMBEDDED
BIFROST = CONNECT / KEEP / RESOLVE. Manage device identity, service/App discovery, truthful running/stopped/unknown state, measurable health, start/stop/restart, representation endpoints, storage/network/resource status where available, logs, package/version/update state, APK compatibility/Package Manager handoff, remote management representation and Server Mode supervision. REGISTERED != WORKING. Never absorb SKALD/NOSTOS domain logic.

SKALD
Primary server workload and standalone Media & Entertainment/media-content specialist. Android UI is a lightweight representation/control surface over authoritative headless service. Preserve unified library, Movies/TV, browse/search, identification, metadata, artwork, subtitles, downloads/ingest, jobs/activity, review, storage, settings/diagnostics, watched/progress, collections, background library management, direct/remote serving, Travel Packs, Daily Episodes and modular providers where recovered.

SKALD EMBEDDED MEDIA CONTRACT
MKV commonly source. Inspect streams; metadata/artwork/subtitles; remux compatible sources to Apple-compatible MP4/M4V using VIDEO STREAM COPY ONLY; preserve compatible audio/chapters/track metadata where possible; verify before atomic promotion; retain source until verified. NO VIDEO TRANSCODING on SM-T110. Outcomes: REMUXED / SOURCE PRESERVED / TRANSCODE REQUIRED-deferred. Reuse mature FFmpeg/ffprobe with verified API17/ARMv7 build. Prefer microSD for Downloads/Processing/Library. SMB may expose managed Incoming, Downloads, Library/Movies, Library/TV; never credentials/internal DB/runtime secrets/private config/temp.

NOSTOS
EDEN Home & Household specialist. On this target runs as lightweight headless household-information server. Established responsive Web UI remains main management interface. Domain: household/family; sites/structures/spaces; possessions/assets/inventory; provisions/supplies; chores/tasks; maintenance schedules/records; household documents/records; utilities where applicable; history; search; settings; multi-user access where established; local-first persistence; backup/restore. Android APK is lightweight representation over same service/data, never competing implementation.

NOSTOS EMBEDDED EXCLUSIONS
Do not add Home Assistant, Homebridge, Matterbridge, Node-RED, HomeKit, Matter, MQTT, smart-home automation, alarm/security/camera processing or AI merely because broader NOSTOS concepts may support them elsewhere.

EDENOS HOME / FILES
Home: lightweight launcher/status surface; launches EDEN and normal third-party APKs; exposes Device/Experience modes; consumes rather than owns service state. Files: lightweight internal/microSD/Downloads/Documents/permitted-SKALD access; reuse mature SMB/network providers.

OPTIONAL TABLET APPS
Prefer existing lightweight third-party APKs for browser, IMAP/SMTP email, office compatibility, PDF/EPUB, text/Markdown, gallery/player, archives and basic utilities. Capability on disk != resident RAM use. No Play Store requirement.

RESOURCE PRIORITY
Server Mode resident set approximately Android core + BIFROST Embedded + SKALD headless + NOSTOS headless + SMB + essential network/storage. SKALD has workload priority. Measure actual RAM/CPU/storage/startup/throughput/UI responsiveness/stability; never invent measurements.

REMOTE MANAGEMENT
BIFROST manages machine/service state; SKALD media; NOSTOS household. Normal administration should not require SSH; ADB/SSH remain expert/development/recovery. Never expose SMB directly to public Internet.

CURRENT BUILD MILESTONE
Produce installable API17/ARMv7 candidates: edenOS-Home.apk, BIFROST-Embedded.apk, SKALD.apk, NOSTOS.apk, edenOS-Files.apk. Each builds in Codex-supported development workflow, installs independently, has truthful metadata, renders 1024x600, avoids ARM64/Play Services/AI/cloud requirements, and reports UNKNOWN/UNAVAILABLE instead of fake backend success.
