# Physical-device checklist (iPhone 13-class minimum baseline, modern iPhone, iPad)
Mark an item only after observing it. Simulator never proves camera, Vision, MusicKit, HealthKit, recording, orientation, signing, thermal.
Run on: iPhone portrait, iPhone landscape, iPad portrait, iPad landscape.

A. Install/launch: builds, installs, launches, correct name "SWAYcore Dance & Fitness", icon. (INSTALLED/LAUNCHED are not acceptance.)
B. HealthKit: no crash on first Health request (entitlement change U-04); permission sheet appears; denied state handled.
C. Calibration (exact order): STEP INTO VIEW, WAVE LEFT, WAVE RIGHT, LIFT LEFT FOOT, LIFT RIGHT FOOT, JUMP, READY TO SWAY.
   - Title for the jump step reads exactly JUMP.
   - Wrong gesture does not advance; stand still 30 s with the left hand held out: WAVE LEFT must NOT complete.
   - Step out of frame mid-step, return: progress restarts for that step only, earlier steps stay.
   - Rotate the device mid-calibration: jump baseline resets; calibration still completes.
   - Wait 60 s on one step: help offer appears (keep trying / follow-along).
D. Workout: nothing runs before READY; COACH keeps dancing when YOU is lost; YOU fades on loss and returns on reacquire.
E. Scoring truth: stand still out of frame, no score accrues; stand with only the upper body visible, no PARTIAL/GOOD awarded; match the pose, GOOD shows; do the wrong move with full body visible, NOT MATCHED shows.
F. Learn: tempo 20 BPM is really slow (about 3 s per beat); counts 1-8 select the exact pose; pause freezes count and COACH.
G. Beats: generated, local file, Apple Music (permission), Shazam anchor; pause/resume stays aligned.
H. Create / .swaypack: create, save, share, import on a second device, identical timing.
I. Record Me / Record SWAY: Photos permission, file saved, shareable.
J. Performance: sustained frame rate and temperature after 15 minutes; note memory.
K. Accessibility: VoiceOver on calibration and workout; reduced motion; large text.
L. Production character (once it exists): silhouette readable at workout distance, clean deformation in all 21 clips, no tearing at shoulders/hips, YOUR DANCER customisation visible.
