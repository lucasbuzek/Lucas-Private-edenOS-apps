# Existing Model + Blender Research Authority Brief
Goal: avoid unnecessary from-scratch character modelling while preserving SWAY's production direction and common rig.

Candidate existing/base models must have: exact recorded license/provenance permitting intended modification/app distribution/required redistribution; stylized-human proportions compatible with slightly Memoji-inspired but not photorealistic direction; strong readable silhouette; clean topology/deformation at shoulders/elbows/hips/knees/ankles; ability to adapt to SWAYHumanoid-v1 23-joint contract without a second choreography engine; appropriate customization path; mobile-suitable polygon/material/texture footprint; Blender 5.2.2 LTS editability and Apple RealityKit/USD export path.

Use existing models as base geometry/rig sources when they satisfy those gates. Availability alone is not acceptance. Build 153 avatars are not visual authority. Memoji is inspiration only; SWAY is only slightly more realistic/stylized-human and silhouette readability is prioritized.

Any research/handoff must return a candidate table containing source, exact license, redistribution/modification terms, rig/topology notes, conversion effort, mobile suitability and suitability for Lucia while retaining the shared five-instructor architecture. No model is promoted until licensing + structural + visual + physical gates pass.
