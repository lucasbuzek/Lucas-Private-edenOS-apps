## Architecture and product
SWAYcore is the reusable core; Dance & Fitness is the immediate product. One movement/choreography truth, one compatible humanoid contract, one musical timeline and one session state feed Learn, Workout, tracking, scoring, Beats and creation. Primary navigation: HOME · MOVES · BEATS · PROFILE. Core loop: WATCH -> COPY -> MATCH -> COMBO -> SCORE -> UNLOCK -> DANCE. Content: Move -> Variation -> Combination -> Routine -> Workout -> Challenge -> Program. Mastery: Discovered -> Learning -> Familiar -> Mastered.

## Alpha surfaces and platforms
Production Home, Moves, Move Detail/Learn/Practice/Create, Beats, Setup, six-action Calibration, Workout, Results and Profile. No developer-dashboard UI or placeholders. iPhone and iPad, portrait and landscape. iPhone 13 minimum direction; current physical target iPhone 15 Pro Max.

## Movement / Learn / timing
A deterministic movement definition owns counts, poses, transitions and timing. Learn and Workout/scoring use the same truth. Learn supports counts 1–8, play/pause, mirroring, concise synchronized instruction and user tempo (established implementation range 20–180 BPM). One musical timeline owns beat -> downbeat/bar/phrase -> displayed count -> move -> repetition -> COACH animation -> visual/spoken cue -> expected YOU -> scoring. No independent workout timers advance choreography/cues/scoring.

## Beats and music
Generated rhythm, compatible local/imported audio and supported Apple Music are sources. Local analysis targets BPM/onsets/beat grid/confidence. Shazam is recognition/alignment/preflight evidence, not the sole clock. Apple Music failure/authorization must not disable generated/local Beats.

## Tracking / Calibration / YOU
Tracking is optional and on-device; camera frames are not saved or transmitted for movement tracking. Six-action calibration is exactly STEP INTO VIEW -> WAVE LEFT -> WAVE RIGHT -> LIFT LEFT FOOT -> LIFT RIGHT FOOT -> JUMP -> READY TO SWAY. Calibration owns the experience until READY. During camera-tracked Workout, YOU is the live graphical/translucent user silhouette over the performance stage. Vision skeleton is diagnostic input, not production YOU. Tracking loss does not stop COACH; YOU fades/reacquires. Follow-Along can bypass tracking/calibration via countdown.
