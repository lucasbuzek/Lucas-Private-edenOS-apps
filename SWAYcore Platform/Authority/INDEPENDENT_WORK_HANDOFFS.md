## Per-provider review packet (always return)
1. Exact baseline/version and input SHA-256, original source/history and Git ref; no implied cleanLKG.
2. Task-specific spec references, expected external behavior and role/tenant/access boundary; which product owns the feature.
3. Changed file list or patch with hashes and reversible apply/rollback; no overwrites/side-effects outside owned lane.
4. Positive, negative and offline/device tests; list PASSED, FAILED, UNKNOWN separately, with actual logs.
5. Visual/brand review and privacy/rights notes. Disclose any current tool/account unavailability.
6. Integration PR proposal to ForgeMASTER, product chat acceptance and shared Engine regression. No direct push/merge to canonical main without permission and protection checks.
