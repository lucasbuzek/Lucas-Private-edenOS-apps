# Physical acceptance checklist (iPhone 15 Pro Max, iPad portrait + landscape)
Installed ≠ functional ≠ accepted. Mark each item only after observing it.
1. Launch; coach renders as an articulated 3D character (not a diagnostic message).
2. Learn: select count 1–8 shows that exact pose; pause freezes; mirror works; tempo slider.
3. Start Tracking: permission → STEP INTO VIEW → WAVE LEFT (use your LEFT hand; if the wrong step completes, flip ND-013) → WAVE RIGHT → LIFT LEFT/RIGHT FOOT → JUMP → READY TO SWAY → countdown → workout.
4. Nothing (timer/score/speech/move progression) advances before READY.
5. Step out of frame: reposition cue, YOU fades, no score accrues; return: YOU reacquired.
6. Results: score shown only with sufficient camera evidence; otherwise "not enough evidence".
7. Create Move (manual + camera) → save → export .swaypack → import on second device.
8. Beats: generated styles play; audio file analysis returns tempo; Apple Music search/play; Shazam; Health save (after permission).
9. Record Me → Photos/Files/Share.
10. iPad uses space (side-by-side layouts); rotate mid-session without losing state.
11. Kid Dancers: camera off by default; grown-up gate; no scoring claims without camera.
12. SWAYZ → export → open in Dance & Fitness → identical timing.
13. Studio (iPad + Mac): create people/class/plan/membership/enroll/attend/invoice/pay; quit/relaunch persists.
